# شب‌تاب

نورت را تا آخر شب روشن نگه دار.

یک بازی کوچک مرورگری: شب‌تاب را حرکت بده، قطره‌های شهد را جمع کن تا نورت پر شود، و از خفاش‌ها دور بمان.

**بازی آنلاین:** https://honygol-cmyk.github.io/shabtab/

## کنترل‌ها

- **حرکت:** کلیدهای جهت یا W A S D
- **موس و لمس:** نگه دار تا شب‌تاب دنبالت بیاید
- **شروع:** Space یا کلیک
- **صدا:** M

ساخته‌شده با [Phaser](https://phaser.io/).
